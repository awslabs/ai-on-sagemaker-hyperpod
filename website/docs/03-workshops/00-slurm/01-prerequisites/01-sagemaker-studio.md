# SageMaker Studio IDE

For this workshop, we'll use [SageMaker Studio Code Editor](https://docs.aws.amazon.com/sagemaker/latest/dg/code-editor.html) for convenience. It's a fully integrated development environment (IDE) based on Visual Studio Code that provides a ready-to-use environment in the cloud with the AWS CLI and federated account credentials already set up for you.

:::note
If you prefer, you can use AWS CLI on your own computer instead. Just follow the [Configure AWS CLI](./02-aws-cli.md) instructions to install the AWS CLI and access temporary credentials for Workshop Studio.
:::

## Key Features

- **Familiar Layout**: Familiar VS Code layout with support for multiple tabs and panels.
- **Terminal Access**: Access to a terminal for running shell commands directly within the editor.
- **Extensions**: Support for VS Code extensions to enhance functionality.
- **Collaboration**: Share notebooks and code with team members easily.

## Getting Started

1. Navigate to your [SageMaker Studio](https://console.aws.amazon.com/sagemaker/home?#/studio-landing) console.
2. Click the button **"Open Studio"**.
3. From there navigate to **"Code Editor"** and click **"Open"**.
4. Choose your favorite theme.
5. Open the terminal at the bottom of the screen.

For more detailed information, refer to the [AWS SageMaker Documentation](https://docs.aws.amazon.com/sagemaker/latest/dg/whatis.html).
